# Procedimentos do SISREG III nas APACs

- **Branch da API:** `feat/registro-atividade-municipios`
- **Migration:** `20261114120000_procedimentos_sisreg`
- **Compatibilidade:** **aditiva**. Nenhum valor existente foi renomeado ou removido; APACs já gravadas não mudam.

## O que mudou

O enum `Procedures` (campo `procedure` das APACs) ganhou **116 valores novos** (de 72 para 188), cobrindo a
lista de 186 procedimentos do SISREG III. A lista tem repetições e variações do mesmo procedimento; elas foram
unificadas, e os que já existiam no ICOS foram mantidos com o nome atual.

Endpoints afetados (só passam a aceitar/devolver os valores novos, sem mudança de formato):

| Endpoint                          | Efeito                                                                    |
| --------------------------------- | ------------------------------------------------------------------------- |
| `POST /apacs`, `PATCH /apacs/:id` | `procedure` aceita os valores novos. Valor fora do enum continua → `400`. |
| `GET /apacs`                      | `procedure` pode vir com os valores novos.                                |
| `POST /reports/apacs`             | `countByProcedureInPeriod` pode trazer as chaves novas.                   |
| `GET /notifications`              | `urgentApacs.items[].procedure` pode vir com os valores novos.            |

## Padrão dos nomes

- Maiúsculas, sem acento, palavras separadas por `_`; o `-` do SISREG vira `_`.
- Faixa etária no fim: `_PEDIATRIA` (o SISREG às vezes escreve "PEDIATRICA"); a versão adulta não leva sufixo
  (`CONSULTA EM CIRURGIA VASCULAR - ADULTO` → `CONSULTA_EM_CIRURGIA_VASCULAR`).
- Subárea oncológica: sempre `_ONCOLOGIA` (o SISREG mistura "ONCOLOGIA" e "ONCOLOGICA").
- Lateralidade de olho: `_OD` / `_OE` (o SISREG mistura com "OLHO DIREITO/ESQUERDO").
- Alguns nomes foram encurtados por causa do limite de 63 bytes dos enums do Postgres (ex.: biópsia, vitrectomia,
  facoemulsificação com `LIO` = lente intraocular). O texto completo fica no label.

## O que o front precisa fazer

Em `src/lib/apac.ts`, adicionar os valores em `APAC_PROCEDURE` e os labels em `APAC_PROCEDURE_LABEL`
(o `Record<ApacProcedure, string>` não compila sem o label). O combobox já ordena pelo label e busca sem acento, então
não precisa de outra mudança. Se houver algum agrupamento por tipo (consulta × exame), os valores abaixo já vêm separados.
